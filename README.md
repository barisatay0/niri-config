# niri-config

Niri scrollable-tiling Wayland compositor configuration.

## Features & Bindings

- **Launcher:** [Vicinae](https://vicinae.com) (`Mod + Space`)
- **Terminal:** `foot` (`Mod + Enter`)
- **Status Bar:** `ironbar`
- **Wallpaper:** `swaybg`
- **Network:** `nm-applet`

## Installation

```bash
mkdir -p ~/.config/niri
cp config.kdl ~/.config/niri/config.kdl
```
